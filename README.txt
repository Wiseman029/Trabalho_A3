CHAPECODE ACADEMY — VERSÃO COM IMAGENS DO ANEXO 1

Esta versão utiliza as imagens incorporadas no arquivo Anexo 1.docx: logomarca, imagens dos três serviços e fotos dos profissionais.
As imagens originais foram copiadas para img/anexo/.
Páginas: index.html, servico1.html, servico2.html, servico3.html, empresa.html, contato.html, depoimentos.html e blog.html.
Tecnologias: HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons e JavaScript.


ATUALIZAÇÃO: O cabeçalho foi padronizado no estilo aprovado pelo usuário, usando a imagem original do Anexo 1. Na página inicial, o carrossel utiliza as imagens originais do Anexo 1 em um espaço de altura fixa e object-fit: contain, sem alterar as imagens das páginas individuais de serviço.


Depoimentos: foram usadas fotos ilustrativas de banco de imagens do Unsplash para os avatares dos depoimentos.

V18: ajustada a foto ilustrativa do depoimento de Gabriel Rodrigues para uma foto masculina do Unsplash e substituídas as imagens das publicações do blog pela logomarca original da ChapeCode Academy.

V19 (back-end): formulários de Orçamento e Contato gravam em banco (SQLite) via API Flask; o catálogo de Serviços é carregado do banco. Veja o README.md na raiz do projeto.
